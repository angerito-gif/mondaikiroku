# 問題記録（もんだいきろく）

間違えた問題を記録しておくと、忘却曲線に沿って復習日を自動で決めてくれるスマホ向けWebアプリ（PWA）です。
問題の中身は保存しません。「どの問題集の、何ページの、何番か」だけを記録します。

- ログイン・サーバーは不要です。データは端末のブラウザ内（IndexedDB）に保存されます
- ホーム画面に追加でき、オフラインでも動きます
- JSONファイルでバックアップと復元ができます

## 復習のしくみ

登録した翌日が1回目の復習日です。以降は **1日 → 3日 → 7日 → 14日 → 30日** の間隔で出題します。

| 結果 | 次回 |
|---|---|
| ○ できた | 次の間隔へ進む。30日間隔の復習で「できた」なら**卒業** |
| △ あやしい | 同じ間隔をもう一度 |
| × できなかった | 最初（1日後）に戻る |

- 次回の復習日は「実際に復習した日」から数えます
- 日付は端末の時刻の0時で切り替わります

## 使い方のコツ

- 問題番号は `3, 5, 7-9` のように入力すると、まとめて登録できます
- 問題集の候補をタップすると、その問題集で前回使った科目が自動で入ります
- 復習の評価や削除は、直後に出る「元に戻す」で取り消せます

## 無料で公開する手順（GitHub Pages）

このリポジトリは、ビルド不要の静的ファイルだけでできています。GitHub Pages にそのまま置けば動きます。

1. GitHub でこのリポジトリ（`angerito-gif/mondaikiroku`）を開く
2. **Settings → General** の一番下（Danger Zone）で **Change visibility → Public** にする
   ※無料プランで GitHub Pages を使うには公開リポジトリが必要です。公開されるのはアプリのコードだけで、勉強データは各自の端末内にあるので外には出ません
3. **Settings → Pages** を開く
4. **Build and deployment** の Source を **Deploy from a branch** にする
5. Branch を **`main`**、フォルダを **`/ (root)`** にして **Save**
6. 1〜2分待つと、ページ上部に URL が表示されます
   → `https://angerito-gif.github.io/mondaikiroku/`

### スマホのホーム画面に追加する

- **iPhone（Safari）**：URLを開く → 共有ボタン（□に↑）→「ホーム画面に追加」
- **Android（Chrome）**：URLを開く → 右上の︙ →「ホーム画面に追加」（または「アプリをインストール」）

> **iPhone の場合は、必ずホーム画面に追加して使ってください。**
> Safari のタブで開くだけだと、しばらく開かなかったときにデータが消されることがあります。ホーム画面から起動するアプリは、この削除の対象外です。

### 機種変更・バックアップ

設定 →「JSONファイルに書き出す」で保存します。新しい端末で「JSONファイルから読み込む」を選べば復元できます。
アプリはバックアップから14日以上経つと、ホーム画面でお知らせします。

### 別の方法：Vercel

1. https://vercel.com に GitHub アカウントでログイン
2. **Add New → Project** でこのリポジトリを選ぶ
3. Framework Preset は **Other**。設定は変えずに **Deploy**
   （Vercel ならリポジトリが非公開のままでも使えます）

## 開発メモ

```bash
npm start      # http://localhost:8000 で起動（python3 の簡易サーバー）
npm test       # 復習ロジックのテスト（Node.js 18+）
```

| ファイル | 内容 |
|---|---|
| `index.html` | 画面の骨組み |
| `css/style.css` | スタイル（ダークモード対応） |
| `js/app.js` | 画面描画と操作 |
| `js/srs.js` | 復習スケジュール・日付計算・番号の分解・バックアップ処理（純粋関数） |
| `js/db.js` | IndexedDB の読み書き |
| `sw.js` | オフライン対応（Service Worker） |
| `icons/render.cjs` | `icon.svg` から PNG アイコンを生成（Playwright を使用） |

**アプリを更新したときは、`sw.js` の `VERSION` を必ず上げてください。** 上げないと、利用者の端末で古いキャッシュが使われ続けます。
更新は、利用者がアプリを開いたときにバックグラウンドで取り込まれ、次に起動したときに反映されます。
